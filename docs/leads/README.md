# Lead materials (handoff copies)

Working copies of the sales tools built on 2026-11-01, kept here so anyone with repo access can
pick them up.

- `lead-playbook.html`: the Crossroads Lead Playbook. The live, shared version (with the call
  tracker and the weekly $5,000 deposit goal) is the claude.ai artifact
  https://claude.ai/artifact/4CYGKfVbVmcpdN555uFdPQ. This file is its source. Republish it to that
  URL to update the live page; opening it as a plain file shows the scripts but not the shared
  tracker.
- `claude-in-chrome-holiday-party-leads.md`: brief to paste into Claude in Chrome. It pulls phone
  numbers for the holiday party venues, finds November and December events, and works Jake's
  LinkedIn (linkedin.com/in/sbwjacob). It never sends messages.
- `gigsalad-thebash-profile-kit.md`: everything to paste into GigSalad and The Bash profiles.

Prices used everywhere: weddings $1,000 DJ and MC ($500 deposit); corporate $1,500 for DJ and sound
($1,000 deposit), acoustic and bar quoted per event; wedding bar $250 for one bartender or $400 for
two, never called a minimum.
