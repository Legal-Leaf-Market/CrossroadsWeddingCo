# Trifold pamphlet

`crossroads-trifold.pdf` is the print file: letter paper, landscape, two pages, C-fold.

Printing: actual size / 100% (not "fit to page"), two-sided, **flip on short edge**.
Fold the narrow left panel of page 1 in first, then fold the cover over it.

`trifold.html` is the source. Edit it, then save it as a PDF from Chromium
(margins: none, background graphics: on). Prices are copied from `lib/site.ts`;
if a rate changes there, change it here too.
